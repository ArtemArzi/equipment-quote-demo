# Демо подготовки КП

Одностраничный прототип на условных данных: выбор клиента и сделки, поиск товаров по названию/артикулу, количества, пересчёт, срок поставки, предпросмотр, локальный черновик, выгрузка HTML и печать в PDF.

Без сборки, библиотек, внешних ресурсов, авторизации и реальных интеграций. Открывается как статический сайт.

## Запуск

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8766/

## Проверить

- Начальная сумма 310 000 ₽, выпуск заблокирован из-за пустого срока.
- Поиск `СТ-03` позволяет добавить товар без цены; выпуск остаётся заблокированным.
- Поиск `неизвестный-999` показывает отсутствие результатов.
- Количество `0`, отрицательное, дробное, текстовое или больше `10000` блокирует выпуск.
- При количестве подъёмника `3` сумма 790 000 ₽.
- Заполнить срок, сохранить, перезагрузить: клиент, товары, количество и срок восстановятся.
- Скачать HTML, открыть его, использовать печать / сохранить PDF.

Условные правила демо: положительное целое количество от 1 до 10 000, минимум один товар; цена известна у каждой позиции; заполненный общий срок поставки. Это не правила конкретной компании. Налоги, скидки, наличие и коммерческий эффект не подтверждены. Сохранение только в localStorage текущего браузера и адреса сайта.

## Размещение

Подходит для GitHub Pages: публикация из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. В репозитории только исходники демо и эта инструкция.
